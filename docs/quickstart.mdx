## Run it

<Steps>
  <Step title="Scan">
    ```bash
    npx astro-doctor@latest ./src
    ```
    Or install it: `npm i -D astro-doctor`
  </Step>
  <Step title="Fix errors first">
    `error` means broken, insecure, or silently ignored — fix or prove wrong.
    Then `warning`: real cost, fix unless you can cite why not.
  </Step>
  <Step title="Re-scan to 100">
    Score is asymptotic — watch it rise as you fix.
  </Step>
</Steps>

<Note>
  Exit code `1` means error findings exist. Gate CI on it.
  `--json` gives machines `{ ok, score, diagnostics[] }`.
</Note>

## Suppress explicitly

No allowlists — one line, with a reason:

```astro
<!-- astro-doctor-ignore-next-line astro/no-unsafe-set-html -- trusted SVG sprite -->
<span set:html={SOCIAL_SVGS[label]} />
```

Also available: `astro-doctor-ignore-line` (same line), bare `astro-doctor-ignore`
(all rules on those lines), and file-wide `astro-doctor-ignore-file <rule>`.
