title: Coding agents
description: Teach your agent to run astro-doctor and apply fixes.
---

<Steps>
  <Step title="Install the skill">
    Copy `skills/astro-doctor/SKILL.md` from the repo into your agent's skills directory (Claude Code, Cursor, Codex, OpenCode).
  </Step>
  <Step title="Run the loop">
    After every Astro change: `astro-doctor --json` → fix `error` findings first → re-scan until clean. Severity policy, per-rule fix recipes, and the suppression doctrine (explicit reason, never bulk-suppress) are in the skill.
  </Step>
</Steps>
