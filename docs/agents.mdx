---
title: Coding agents
description: Teach your agent to run astro-doctor and apply fixes.
---

Copy `skills/astro-doctor/SKILL.md` from the repo into your agent's skills directory (Claude Code, Cursor, Codex, OpenCode). It covers when to run the doctor, how to read `--json`, severity policy, a fix recipe per rule, and the suppression doctrine (explicit reason, never bulk-suppress).

Suggested loop: run `astro-doctor --json` after every Astro change, fix `error` findings first, re-scan until clean.
