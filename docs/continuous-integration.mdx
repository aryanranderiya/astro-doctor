---
title: Continuous integration
description: Gate pull requests on astro-doctor errors.
---

<Steps>
  <Step title="Install the workflow">
    ```bash
    astro-doctor ci install
    ```
    Writes `.github/workflows/astro-doctor.yml`.
  </Step>
  <Step title="Push a PR">
    Full scan runs on PRs and pushes to `main`. Any `error` diagnostic fails the check; the JSON report uploads as an artifact.
  </Step>
</Steps>

<Note>
  No CI available? Every gate below stays valid locally: `astro-doctor --json` exits 1 on errors, and `astro check`, `biome check`, and `astro build` cover types, style, and compilation.
</Note>
